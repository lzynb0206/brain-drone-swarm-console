# 逐试次串行记录的锁定分析

2026-11-19，在本次重算个人串行结果前记录。该数据已用于过去的方法探索。公开 SSVEP 模块本次的跨库结果已知，因此这里只做探索性验证，新招募受试者才用于独立确认。

纳入控制台同一时钟的 formal / serial_pair 原始 NPZ，同一人同一 run 同一 pair，SS 先于 MI。主分析要求每个 run 至少 6 个非空区块，区块 1–4 校准，所有后续区块连续留出。旧数据中短程调试、只剩外部 BDF 的双机记录不进入同一时钟分析。保存漏配、坏时钟、无可用信号及短 run 计数。仅排除不可能处理的信号和时序；单列质量状态子集。不按正确率或历史 good 标签筛人。

六个频率 8–13 Hz。每次从 SSVEP onset +0.14 s 取 1.5 s，用可用的已命名后部通道和公开分支的 FBCCA。在校准块估计候选 k 在真实非 k 试次的平均 FBCCA 分数，测试时逐频减去。原始分、同试次减其他五频均值及开头实录八段空闲逐频均值作对照。后者须在首次任务前实录。校准 Platt 的标签是修正后频率是否正确，校准输入为按区块交叉拟合的相对分差。上限和分母按公开代码。主方法局部重拟合，适用于公共六电极到本地五电极的变化。公开库参数直迁单列。

MI 取 MI 任务开始后前 3 s，中央三路、8–30 Hz、收缩 CSP+LDA，输出 q 为所判手别的模型概率。主分数 p*q 估计两个子决策均正确。分解是工作模型，两阶段相关或发生校准漂移时会失准。主比较为无逐试次前序信息的“校准块交叉预测 SSVEP 平均正确率 × q”。预设其次与 p×训练 MI 正确率、训练联合正确率、分差×q、单独拟合的联合 logistic 作对照。主指标为受试者等权的联合正确性 Brier 差（各人内部汇总试次）。原假设另比较同样输入 MI logit 的 logistic 校准分类头，加入 p 与 p×MI logit 的增量。预测方向与判断整条命令可靠性分别计量。错配对照在留出块内循环移位 p，MI 信号及真实结局不动。

报告全覆盖率的分子/分母、负对数似然、按训练分数第20百分位冻结阈值的实际覆盖率与错误数，以及每个留出 run 精确相同80%覆盖的离线排序对照。拒绝不算成功。旧样本只有两人，不计算群体显著性。确认数据使用相同脚本及预先冻结的 primary 分支，所有人报告，不按结果修改解码窗口或选择电极。
