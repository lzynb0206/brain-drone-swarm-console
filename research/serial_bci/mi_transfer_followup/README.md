# 前序 FBCCA 正确概率能否帮助后续运动想象

建议论文题目为《串行 SSVEP–MI 中，前序视觉决策置信度能否改善运动想象解码？》。可以从本项目已有的程序、开发数据结果和独立验证方案开始写方法与开发结果。新队列锁定后的数据决定摘要能写到哪一步。

## 已经从真实脑电得到什么

全部主要比较都使用同一档案 ID、同一次任务、同一采集时钟的成对原始脑电。每个模型都输出左右手；结果可追溯到原文件哈希、前段目标与后段手别。原始 91 次与过去的分析重叠，本轮结论属于开发研究。另有一个未用于主分析的采集 ID，完整保留了 16 对短正式记录。

| 实测条件 | MI 自身调权 | 同次前序 P 加入调权 | 改对 / 改错 |
|---|---:|---:|---:|
| 两个 ID，三个会话，先训练后测试 | 44/91 | 44/91 | 0 / 0 |
| 同一 ID，11 月 7 日训练，14 日整场测试 | 37/84 | 37/84 | 0 / 0 |
| 11 月 3 日的另一人训练，第三个 ID 整段测试 | 9/16 | 9/16 | 0 / 0 |

跨日 84 次含有前表中已评过的 36 次，不能把三行相加来报样本量。历史各会话共用任务种子。第三个 ID 的 16 对是以前未进入主评估的档案记录，全体数据均属于开发阶段。三个采集 ID 也不足以建立人群规律。宽带 CSP 的原始 39/91、旧逻辑头的 37/91、双频带的 44/91 是不同的 MI 处理方式。真正归于 P 的增量是每行横向的差。

### 为什么会得到零

- 原 91 对中 1.5 秒 FBCCA 判对 15 次，接近六选一。平均 P 为 0.174，逐块区分视觉对错的 AUC 只有 0.308。用各会话训练命中率为常数就有 Brier 0.13249，逐次 P 为 0.13549，越小越好。前段知道不同会话平均有多难，对同一块中哪一次看对的分辨率却很差。视觉 4 秒窗将命中提高到 21/91，同块 AUC 达到 0.623，三个会话的方向均转正。该窗的视觉 Brier 为 0.18922，优于它自己的训练常数 0.19184，后段 MI 仍是 44/91 对 44/91。 事后以 4 秒复算跨日和跨人，后段仍为 37/84 对 37/84、9/16 对 9/16。这两组 4 秒 P 的同块视觉 AUC 分别为 0.453 和 0.444，提示会话内结果尚未推广到免重新校准的场景。
- 两个 MI 频带只在 12/91 次给出相反手别。拟合出的 P 系数在三个会话依次约 0、+0.039、−0.014。门控允许 P 改变手别，实际没有学到稳定的调权方向。原始质量记录另有 32/91 段 MI 出现 C3、C4 近重复标记，需要实物核查。
- 一个可复验线索是在视觉事后判对的 15 次中，宽带 MI 对了 10 次，而视觉判错的 76 次中，MI 对了 29 次。其中一人单次会话贡献了 5 个双正确。这个分组用到了事后答案，不能将差值写成 P 带来的识别增益。
- 为检验 P 是否压缩掉了有用信号，增加了独立的探索实验。两维后段中央侧化模型为 48/91，以视觉期同次中央脑电作参考后为 49/91，救回 16 次且损害 15 次；第三个 ID 从 10/16 降到 9/16。以当次 P 代替固定平均 P 加权参考，分别为 49/91 对 49/91、10/16 对 10/16。主样本真配对结果落在块内随机错配的参考范围内。该探索不足以替换预定主比较。详见 [前段中央脑电参考结果](reference_results/前段中央脑电参考结果.md)。

## 冻结的算法

独立新队列正式锁定 **刺激开始后 0.14–4.14 秒的 4 秒 FBCCA 窗**，1.5 秒保留为敏感性对照。这个决定在真实开发数据分析之后、新人采集之前作出，依据前段 P 自身的判别表现。P 的真值定义为“当前 FBCCA 选择的频率与本次目标相符”。用前四个校准块内的非目标背景校正六个 FBCCA 分数，第一、二名相对分差经留块交叉预测再做逻辑校准。后续每次实际解码时，只观测前段脑电并计算 P；当次真频率和手别不参与任何可部署预测。三电极 MI 信号分别在 μ（8–13 Hz）和 β（13–30 Hz）频带拟合 CSP 与收缩 LDA，得到两个右手分数。令 w 为 μ 权重，则右手分数为 wqμ+(1−w)qβ。基线仅依两频带自身确信程度差调 w，实验臂额外依当次 P 调 w。相同训练数据、相同测试数据和阈值 0.5，比较两者的受试者等权平衡准确率。

权重从个人校准块的折外预测拟合，共享同一 Brier 目标和固定正则，系数受约束使 w 始终在 [0,1]。参数、裁剪、滤波器及边界行为见 [解码器实现](experts.py)。这一结构明确了 P 帮忙的途径：当 μ 和 β 给出矛盾手别，且 P 能指出此时哪一带更可靠时，最终决定才可能被纠正。两者独立配平时，单靠 P 猜左或右缺少依据。

## 下一轮怎样做

1. **先做一次独立工程预试。** 用同一设备检查 C3/C4 接线、参考和波形近重复，用光电测量验证屏幕六频和呈现时序。工程预试前四块先看视觉混淆矩阵、8 Hz 误报/漏报及 MI 混淆矩阵；出现持续性近重复或与指令完全不符时，在工程预试阶段修复后再冻结设置。详细操作在 [采集单](acquisition.md)。
2. **正式队列每人 84 对。** 每块 6 个视觉频率 × 2 种独立手别，每格一次，先视觉后揭示手别。每位新受试者和每个会话用各自的任务种子。前四块 48 对校准，后三块 36 对封存测试。保留低 P、视觉识别错误和信号质量提示，按统一时序与文件完整性条件排除。登记所有退出和未写入原始文件的计划试次。新队列只使用新 ID 与正式原始目录。
3. **采满后一次离线计算。** 在仓库根目录，使用下方命令。原始目录可以包含多个受试者的子目录。生成的结果表包含无 P、真实 P、错配 P、分频专家、错误纠正个数、右手概率损失、视觉校准和 8 Hz 误判，机器可读 JSON 另含人均效应区间和各次训练清单。采集台账用来复核所有开组与未完成者。

```bash
.venv312/bin/python -m research.serial_bci.mi_transfer_followup.run --new-cohort \
  --raw "/实际路径/新队列正式原始脑电" --out "/实际路径/新队列分析结果"
```

复算本机的历史开发数据可执行以下命令。

```bash
.venv312/bin/python -m research.serial_bci.mi_transfer_followup.run --historical-challenge
```

## 文章的判断标准

主假设是在新受试者的独立留出块上，真实 P 使全覆盖手别平衡准确率优于 MI 自身调权，预定最小关注效应为 3 个百分点，并检验真实对齐能否超过块内错配、同块同频错配。阈值、样本量情景和判断区间见 [分析约定](design.md)。若只改善视觉校准或 MI 错误预警，文章就明确报告该终点。上限低于 3 个百分点且前后段均有有效信号，才有依据讨论该设置的增益上限。若前段仍接近机会水平，只能定位为前段测量不能支持传递；区间太宽则报告证据不足。

现有正面实证来自独立视觉任务：在 Benchmark 训练、BETA 六类外部留出的 1,680 个试次上，逐频非目标背景校正使 FBCCA 从 1,354 对升至 1,419 对，非 8 Hz 误报为 8 Hz 从 201/1,400 降至 96/1,400，真实 8 Hz 漏判从 14/280 升至 31/280。适合将这项可复现的视觉校准结果作为论文前半部分，再用同人串行试验检验它能否转移。[公共视觉实验](../ssvep/README.md)

已有先视觉后 MI、对 SSVEP 正确概率建模、以及用视觉诱发反应预警 MI 表现的研究。可检验的具体贡献是独立频率与手别、逐试次正确概率、全覆盖频带调权和严格配对对照的组合。现有证据支持写出该问题的实验论文，不足以承诺正向效果或录用。[数据与文献](evidence.md) · [逐试次主结果](results/结果.md) · [P 的原始诊断](diagnostic_results/解读.md)
