# 新队列采集单 · 前序 SSVEP 能否改对后续手别

## 开始招募前

1. 在单独的工程预试编号上固定设备、训练口令、屏幕与座位。用光电二极管逐靶实测 8–13 Hz 的亮度波形、首次亮起与标记的延迟，保存原始测试和显示设置。测定 8 Hz 实际呈现是否正确，并检查 9–13 Hz 靶的实际输出。旧数据中，非 8 Hz 目标误报为 8 Hz 共 25/76 次，实际 8 Hz 漏报 13/15 次。
2. 核对每一条独立导联与参考、地线，尤其是 C3、C4。历史 91 个留出试次中，42 段 MI 和 31 段 SSVEP 带有“通道近乎重复”标记，其中 32 段 MI 的 C4 与 C3 重复。程序的判据为滤后相关系数绝对值至少 0.995。接触异常、接线错误和导电介质之间的连接均值得实物复核，单凭高相关不能确定原因。新队列正式任务前按相同流程检查，保留整改前后预检记录。
3. 每位新参与者及每次计划复测预分配不同的非负整数 seed，范围 0–2147483647。登记匿名 ID、run、seed、屏幕设置、预检编号、软件版本、日期。台账纳入所有已开始和退出者。冻结手别主终点、目标提升 3 个百分点、计划人数和停止规则。本实验的样本量以人的平衡准确率配对差计算，不沿用旧的联合命令 Brier 样本量。启动正式招募前完成课题既定的人体实验与闪烁刺激审批、同意及停止流程。

## 操作台与受试者口令

| 步骤 | 实际操作 |
|---|---|
| 选择硬件 | 在仓库根目录启动 `.venv312/bin/python main.py`。科研工作台“采集”页、停流时选择“SSVEP＋MI · 5+3”，使用本机 250 Hz EEG。核对 CH1–CH8 依次为 O1、Oz、O2、P3、P4、C3、Cz、C4，确认参考与地线，启动数据流。 |
| 选择实验 | “数据采集”页确认新的匿名受试者，实验类型选“SSVEP＋MI 联合实验”，实验方案选“正式任务采集”。展开“实验参数”→“修改实验参数”，勾“采用论文串行方案（84 对、开头 8 段空闲、左右手）”，输入本轮预分配 seed。 |
| 预检与练习 | 独立的“试运行 · 2 组”可用于练习。正式运行点页面底部“开始采集”，在接线确认框点“开始试采检查”，约 6 秒后保存，点“关闭”继续。逐导联检查近重复、平直、工频与过大幅度，保存提示。正式采集中的低 P 或低准确率保留。 |
| 串行任务 | 睁眼静息 5 秒，开头 8 段六靶闪烁时看中央。每个正式试次先提示目标 1 秒，再持续注视指定闪烁靶 5 秒，间隔 1 秒，手别提示 3 秒，出现中央注视画面后想象相应手部运动感觉 5 秒，休息 3 秒。练习时统一左右手想象动作、姿势和起始时刻，双手放松不实际运动。MI 标签应当在前段结束后才向参与者呈现。 |
| 完成及归档 | 每块含“6 个频率 × 2 种手别”各一次，共 7 块 84 对，块间另有空闲。保留每个 run 的原始 EEG NPZ、短静息和空闲、呈现日志、时钟审计、预检与复测记录。记录暂停、操作偏差、中止、缺失阶段及其发生顺序。 |

## 锁定配对与错配检查

- 原始文件中的 `trial_context.random_seed` 及 `config.random_seed`、run 台账和预分配表应一致。通过 `src.services.hybrid_experiment_protocol.build_hybrid_plan(config)` 按 seed 回放，逐个 `trial_index` 比对块号、真实频率和手别。统计完整块每格 1 次、计划与实收、QC 后各频率左右手数。这个回放已在 91/91 个历史留出试次核对成功；三个会话却共用 seed 20261101，因此任务顺序的跨会话重现需要在新人群解除。
- 首次核对采集来源、计划和时间戳后再计算预测。主流程取块 1–4 拟合，块 5–7 顺序留出。屏幕测量及原始元数据提供物理呈现与任务顺序证据。脚本输出的“同人”依赖档案 ID，台账负责识别同一人跨日与重编号。
- 保存原始计划、每次分析的随机数种子和代码版本。按人和块看 P、实际手别、真实目标频率、试次位置、暂停和缺失。位置或频率若能预测手别，或 P 在一块内持续漂移，配对破坏后的统计量可能同时包含时间或刺激效应。冻结模型后在同块循环错位 P；补充检查同块同真实频率内错配。描述可移动试次和可比较正负对，保留缺失后仅剩一个成员的小层。错配分位数用于描述对试次对齐的敏感性。
- `--new-cohort` 用于新的目录。运行主分析后检查每个人以本人数据训练与评估的配对清单，报告原始与可分析分母。参与者等权主比较为全覆盖手别平衡准确率，逐人记加 P 改对/改错数。对 P 的视觉 Brier 和同块排序另行报告。视觉真值只进入事后诊断。

采集页出自 `src/views/research_configuration_view.py`，设备模式出自 `src/services/acquisition_profiles.py`，七块排程出自 `src/services/hybrid_experiment_protocol.py`，信号质量判据出自 `src/bci/preprocessing.py`。

若数据继续采在当前工作站，可在采集前把新队列匿名 ID 逐行写进同一份登记文件。采完后，直接从工作站原始目录按这份登记表离线汇总，不需移动 NPZ。在项目根目录运行：

```bash
.venv312/bin/python -m research.serial_bci.mi_transfer_followup.run --new-cohort \
  --roster "/实际路径/新队列编号.txt" --out "/实际路径/冻结分析结果"
```

结果目录中的 cohort_flow.csv 包括已登记但没有合格数据的编号，acquisition_audit.json 给出已接收数据的种子、逐块 6×2 计数、计划回放差异和缺失。只有未提供名册时，该流程表才限于至少有一对合格数据的 ID。summary.json 另存算法、配置、公共校准参数的哈希与核心依赖版本。

独立工程预试如需直接查看正式锁定的 4 秒 P，仅对工程编号的原始目录运行下列命令。程序只用校准块 1–4，给出 8 Hz 双向错误、视觉 P 对常数的 Brier、同块 AUC、μ/β 的 MI 平衡准确率和 C3–C4 近重复数。

```bash
.venv312/bin/python -m research.serial_bci.mi_transfer_followup.run --calibration-only --raw "/实际路径/工程预试目录" --out "/实际路径/工程预试读数"
```
