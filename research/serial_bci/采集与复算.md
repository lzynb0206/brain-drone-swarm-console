# 新队列串行脑电采集与离线复算

本实验检验一个问题：对于同一次先看闪烁目标、再做左右手想象的记录，前一阶段的正确概率能否改善对“两阶段都判对”的预测？每名受试者贡献一个主效应值。手别是否判得更准单独检验。参与者是否继续下一阶段与系统当前预测结果无关。

## 招募前冻结

1. 由课题负责人按所在机构流程确认涉及人类参与者和视觉刺激的伦理审查、招募范围、知情同意及停止程序。操作员在实验前向参与者解释闪烁和运动想象任务、可随时暂停或退出的方式。用匿名编号登记，身份对应表与脑电数据分开管理。
2. 先用单独编号做工程预试。核验时钟、电极、实测显示频率及事件保存，允许在此阶段改设备设置和算法。预试人与现有历史受试者均独立标注。之后冻结代码版本、公共模型文件、6 个频率、分析窗、校准块数、主终点、排除规则及招募目标。每名新参与者预分配不同的整数种子；将编号、种子、批次、计划日期录于采集台账。
3. 在拟用的显示器、分辨率、刷新率、亮度与全屏模式下，用光电二极管记录每个靶的实际亮度随时间变化，覆盖每个 5 秒刺激段。对照帧日志检查六个实际频率、首次物理亮起相对事件标记的延迟、丢帧和周期稳定性。保存原始光电记录、对应事件、测量设备和显示器设置。设备验收限值由负责人在工程预试后锁定。换屏幕、刷新率或刺激软件后重复设备验证；屏幕帧交换时间给出软件呈现估计。
4. 主效应的规划参数为每人 Brier 差的标准差与目标差值。若最小有意义差值为 0.01，以双侧 α=0.05、目标功效 0.80、一人一个配对差的非中心 t 模型计算，标准差 0.02 对应 **34 名可分析者**，标准差 0.03 对应 **73 名可分析者**。如按 15% 技术失败或退出预留，分别招募 40 和 86 人。标准差来自设计情景。可从独立预试重估标准差，再锁定正式样本量。该计算针对配对均值 t 检验，对脚本的 bootstrap 区间覆盖和功效仍应做情景模拟。论文分别报告计划、招募、完成及可分析人数。

## 每人一次正式采集

| 项目 | 操作 |
| --- | --- |
| 启动 | 仓库根目录运行 `.venv312/bin/python main.py`，进入“数据采集”，选择“SSVEP＋MI 混合”“本机实时 EEG”“正式任务采集”。确认本轮匿名受试者。 |
| 电极与输入 | 在停流状态下应用“候选 5+3 布局”。逐一核对 CH1–CH8 为 O1、Oz、O2、P3、P4、C3、Cz、C4，记录参考和地线，启动本机实时 EEG、标称采样率 250 Hz。 |
| 论文方案 | 点“配置采集计划”，勾选“采用论文串行方案（84 对、开头 8 段空闲、左右手）”。输入**本人的预分配种子**，核对预览显示的种子、84 对和采样布局。每换一人重设种子。 |
| 信号预检 | 点“开始任务采集”，在预检中核实接线、运行 6 秒试采，检查软件报告的采样率、最大间断、标记和通道质量。已保存报告后点预检框的“关闭”继续；按 Esc 或关闭窗口取消本次启动。接线、时钟、采样或标记有技术错误时按报告修正并重新试采。只有信号质量告警时仍可正式采集，保留告警、同次 preflight JSON/NPZ 与编号。不要按幅度、工频或预期解码能力筛人。 |
| 基线与空闲 | 开头采 5 秒不闪烁的睁眼静息，随后采 8 段六靶闪烁且只看中央的空闲。另有 6 段块间空闲。最初 8 段用于固定空闲背景，块间空闲单独保存。|
| 84 组 | 7 块 × 12 对。每块内 8、9、10、11、12、13 Hz 六个频率与左、右手各搭配一次，块内独立乱序。每人每个组合共 7 次。受试者按提示注视目标，按手别提示想象相应手部运动，保持实际双手静止。 |
| 时序 | 单试次依次为频率目标提示 1 s、SSVEP 刺激 5 s、间隔 1 s、手别提示 3 s、中央注视下想象 5 s、休息 3 s。软件的 MI 分析零点是**手别提示结束、想象阶段开始**。纯阶段时长含 14 段空闲及短静息约 27 分钟，另留时间给预检、保存和休息。 |
| 暂停与结束 | 按 P 请求暂停，Escape 可中止。记录中止的区块与试次、技术故障、暂停和参与者退出情况。每人一次正式 run；未经预先规定的重新测试应单列。 |

所谓“校准”有两层。设备预检与光电测试服务于设备验收。每名被试第 1–4 块的 48 对用于算法训练和置信度拟合，按块产生训练集外预测；第 5–7 块的 36 对顺序留作评估。低准确率、低 p、低 q 与系统认为“不易解码”均不能作为删人依据。上表中的计划含 84 幅 SSVEP 任务片段与 84 幅紧接的 MI 任务片段，另有 14 幅空闲 SSVEP 和 1 幅静息。

## 保存与核对

- 保留每次 run 自己的完整目录，叶目录名必须是 run_id。串行文件为 `<pair_id>-ssvep.npz` 及 `<pair_id>-mi.npz`。另保留 `<run_id>-baseline.npz`、所有空闲文件、呈现日志及预检报告。对照试次计划检查 7×12，并登记从未开始和中断的计划试次。
- NPZ 顶层保留 `eeg`（8 通道 × 采样点）、`fs`、`sample_timestamps`、`channel_names`、`subject_id`、`true_label`、`signal_quality` 和 `trial_context`。以 `trial_context` JSON 中的 `run_id`、`pair_id`、`block_index`、`stage`、`record_kind`、`acquisition_purpose`、`clock_source`、`stimulus_lsl_time`、`ssvep_true_label`、`frequency_hz`、`mi_true_label`、`montage_id`、`random_seed` 和 `baseline_trial_id` 定位。MI 的 `preceding_ssvep_trial_id` 必须能回指同一对 SS 文件。两个阶段属同一人、同一 run，共用同一时钟，SS 结束时间早于 MI 开始时间。
- 设备预检 ID 写入 `trial_context.preflight_id`。新报告中 study_technical_ready 表示课题所需技术检查通过，signal_quality_warnings 保留独立的信号质量告警；formal_ready 是同时考虑质量的既有检查字段。历史报告缺新字段时仅兼容已明确通过的 formal_ready；无法判明原因时重新试采。历史资料的空 ID 单独标注；新队列保存相应软件预检报告和独立物理测量证据。软件预检通过不能替代亮度波形标定。在口令、受试者身份、原始文件跨设备汇总前核对匿名编号唯一性。
- 讨论缺失时给出各级分母：招募人数、开始和结束人数、计划/实际配对数、漏单侧数、时间或信号失败数、每人校准/留出可分析数、最终分析人数。默认完整设计每人有 36 个计划留出试次。算法覆盖率使用实际可评分留出试次数；另报每人“获得正确完整结果的试次数 / 36 个计划留出试次”的可用性。不会对失访者填造信号。程序的 `epoch_audit.csv` 记录已落盘片段，完全没有生成文件的退出/漏采由台账补齐，提早退出者仍在流程图中报告。

## 离线复算

在仓库根目录执行。把值替换为本机实际的绝对路径，每次选择全新的输出目录。输入中只放相应队列的原始 run 目录；校准模型和公共参考参数使用已冻结版本。

```bash
# 独立工程预试。只使用第 1–4 块的信号和标签分析。
.venv312/bin/python research/serial_bci/serial/run.py --calibration-only \
  --raw "/实际路径/工程预试原始记录" --out "/实际路径/工程预试结果"

# 正式检验。所有新受试者按方案收齐后一次执行。
.venv312/bin/python research/serial_bci/serial/run.py \
  --raw "/实际路径/仅新队列原始记录" --out "/实际路径/新队列正式结果"
```

先读预试的 `calibration_check.json`，核对 6×2 每格的次数、第 1–4 块留一得到的两阶段混淆矩阵及 8 Hz 误判。用独立工程预试排除标签写反、通道互换、显示频率偏移等问题，登记处理过程。正式采集期间仅检查入组登记、通道、时序和数据完整性，封存后 3 块。

正式输出先查 `epoch_audit.csv`、`summary.json` 中的 `splits` 和台账。按计划每人前 4 块、后 3 块；现有脚本允许在后续留出中至少 2 块可用的 run 进入，其有效试次数和未测原因须逐人列出，并另给完整 7 块子集敏感性结果。请同时核对正式 cohort 是否混入工程预试、既有开发人员、重复运行或已看过结果的参与者。随后读 `trials.csv` 与 `summary.json`，保留原始数据和结果的 SHA-256 清单、代码版本、执行命令与日期。

## 预定主比较

对第 i 个留出试次设 Yᵢ=1 当且仅当频率、手别都判对；qᵢ 取 CSP 判定手别的模型概率，pᵢ 取校准后的 FBCCA 判对概率。比较 `product` = pᵢqᵢ 与 `no_p` =（校准块中交叉预测的 SSVEP 平均正确率）×qᵢ。对每人分别求留出试次的平均 (预测值−Yᵢ)²，得到 **D = Brier(no_p) − Brier(product)**。D>0 表示逐试次前序概率改善联合正确性预测。

论文报告 `primary_brier_gain` 中的每人等权平均 D、改善人数、总人数和被试层重采样 95% 区间（至少 8 人时脚本使用 10,000 次 bootstrap），并列每人结果。区间包括零时，照实报告效应的不确定性。其次报告全覆盖两阶段及联合正确次数／总数、原始分差与两种背景校正或静息校正的 8 Hz 假阳性／非 8 Hz 次数及漏判／真实 8 Hz 次数、校准误差、概率损失、训练阈值下的覆盖率和错误数。同覆盖率排序为离线诊断。另比 `hand_with_p` 对 `hand_mi_only` 的平衡准确率及概率损失，判断前序信息是否改善手别解码。联合可靠性分数改变本身不会改变固定两阶段的分类正确次数。
