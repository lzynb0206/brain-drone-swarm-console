# 前序 SSVEP 置信度与串行 MI 指令可靠性

[中文研究稿](前序SSVEP置信度与串行MI指令可靠性研究稿.docx) 汇总公开数据、独立组合回放和历史真实串行验证。[新队列采集与复算](采集与复算.md) 给出招募前的设备预试、实际采集界面和新数据命令。

## 怎样理解主结果

本项目固定 FBCCA，根据训练集中“其他目标”引起的分数估计每个候选频率的背景。P 的监督标签为本次选中的频率是否正确。后段用 C3、Cz、C4 的三秒 CSP 与收缩 LDA 判左右手，再检验 P 是否改善手别分类、以及对“同一次两个判断都正确”的估计。两个检验使用不同的因变量。

- 在独立于训练库的 BETA 六频子集中，准确率从 80.60% 到 84.46%，非 8 Hz 误触从 201/1,400 到 96/1,400，真 8 Hz 漏检从 14/280 到 31/280。相同校正决策的原分差、Platt 和单调回归 Brier 为 0.1754、0.1101、0.1069。后续比较中，使用最高分与其余五名差值的岭 logistic 将跨库 Brier 进一步降至 0.09052；它在独立组合的 80% 覆盖下达到 64.65%。本地用前四块重拟合全部五维系数后，视觉 Brier 为 0.15588，弱于单维个人校准的 0.13549。故将这项更复杂的方案保留为补充比较。
- 干湿电极附加实验覆盖同一批 102 人。在干电极上直接照搬源概率有明显偏高。在同样 24 条本地校准预算下，原始分只调截距的 Brier 优于再加个人背景校正。六频和十二频的分类结果应分别解释。
- 两个独立单模态试次池的联合 Brier 从 0.23599 到 0.21946。相同 80% 覆盖时，双正确比例从 62.00% 到 63.39%。这是独立分布的组合计算，组合数不增加受试者数。
- 真实历史留出样本有 2 人、3 次会话、91 对。按人计算的联合 Brier 增益为 +0.00248 和 −0.00179。在相同 MI 分类头上加 P 与不加 P 均正确 37/91，CSP 原始分类正确 39/91。新队列检验仍然开放。

## 复算

在仓库根目录执行。已有工作区中的公共数据可直接复用。新机器先按各模块说明取得相应数据，依赖见根目录 requirements.txt 与 requirements-ml.txt。下面的批处理只读取现有数据，会重建本研究目录内的历史计算结果。

```bash
.venv312/bin/python research/serial_bci/reproduce.py
```

新队列只需执行独立入口，输入目录只放本批次；输出为逐试次预测、区块划分、排除审计、受试者等权效应以及可粘入论文的“结果表.md”。新队列不能与已经多次探索的旧队列合并为一次确认试验。

```bash
.venv312/bin/python research/serial_bci/serial/run.py --raw "/实际路径/新队列原始NPZ" --out "/实际路径/本次结果"
```
